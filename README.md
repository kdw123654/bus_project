# 🚌 수원대 7790번 스마트 탑승 진단 & XAI 착석 예측기 (7790 타요?)

> **"지금 오는 7790, 내가 탈 수 있을까? 앉아서 갈 수 있을까?"**  
> 사당역(등교) 및 수원대·신명·아이파크·효행초(하교)를 이용하는 수원대학교 학우들을 위해, 도착 버스의 **일반/전세 여부 판별**과 **실시간 잔여 좌석 및 착석 성공 확률(XAI)**을 정밀 진단해주는 모바일 웹 서비스입니다.

---

## 📌 기획 배경 및 해결한 문제
* **일반 vs 전세버스 혼선**: 지도 앱(카카오맵/네이버 지도)에서는 사당역으로 진입하는 7790번이 일반 광역버스인지 통근·예약 전세버스인지 구별되지 않아 지각하거나 헛걸음하는 문제 해결.
* **상행선(하교 피크) 연쇄 만석 미스터리**: 수원대입구에서 버스를 탈 때, 이미 앞 정류장(효행초, 아이파크, 신명)에서 학생들이 대거 탑승해 만석으로 진입하는 문제를 **연쇄 좌석 차감 알고리즘**으로 사전 예측.
* **등교길(사당역 9출) 줄 대기열 반영**: 버스 자체 잔여석만 보는 것이 아니라, 정류장에 서 있는 학우들의 실시간 줄 대기열과 비사용자 일반 승객 통계를 합산 분석하여 **실질 착석 확률**을 도출.

---

## 🚀 핵심 주요 기능 (Key Features)

### 1. 5대 핵심 정류장 맞춤형 관제 (등교 vs 하교 시각적 분리)
* **🎓 등교 (하행 수원대 방면)**: 사당역 9번 출구 앞 (회차 기점)
* **🏠 하교 (상행 사당역 방면)**: 효행초등학교 ➔ 아이파크정문 ➔ 신명아파트 ➔ 수원대입구 4개 정류장 연쇄 추적

### 2. XAI 설명 가능한 착석 성공 확률 진단 (Explainable AI)
* **차종 스펙 완벽 반영**: 2층 버스(71석) vs 1층 버스(45석) 및 잔여 좌석 정밀 계산
* **상행선 연쇄 좌석 차감 (Kalman Filter)**: GBIS 실시간 차량 위치(`currentStationId`)와 실제 노선 순번(`seq`)을 매핑하여, 버스가 이미 지나친 정류장의 중복 차감을 방지하고 남은 정류장의 승차 인원만 정밀 차감
* **SHAP 지연 기여 요인 분석**: 봉담IC, 과천의왕간고속화도로, 남태령고개 등 66개 구간별 실시간 통과 소요시간(ptts)과 실시간 기상/노면 상태 연동

### 3. 학우 참여형 1초 원터치 줄 제보 & 안심 방어 체계
* **1초 원터치 제보**: 정류장 대기열 상태(여유/보통/포화)를 1초 만에 제보
* **부드러운 Toast 알림**: 브라우저 alert 팝업 없이 앱 같은 부드러운 토스트 알림 제공
* **하이브리드 Rate Limit**: 익명 UUID(`localStorage` + `X-Client-Id` 헤더)로 개인별 쿨다운을 식별하여 캠퍼스 공유 Wi-Fi(NAT IP) 환경에서도 타 학우 제보 차단 방지 + 공인 IP 분당 총량 제한
* **신뢰도 가중치 (Consensus)**: 단일 제보 시 70% 가중치 반영, 2건 이상 교차 검증 시 100% 반영하여 허위 제보 및 트롤링 방어

### 4. 고성능 백엔드 캐싱 & 쿼터 보호
* **공공데이터 API 쿼터 방어**: 제보 등록 시에도 도착 캐시(`CACHE_BUS_ARRIVALS`)를 비우지 않고 유지하며, 제보 요약만 동적 합성하여 API 일일 한도 고갈 방지
* **GBIS 통합 캐시**: 차량 위치 조회와 실시간 도로교통 지연 분석 간 중복 네트워크 I/O를 8초 인메모리 캐시로 통합하여 응답 지연 50% 단축

### 5. 정시 시간표 & 사당역 심야 막차 가이드
* 평일 및 주말 운수사 공식 정시 배차 계획표 조회
* 사당역 00:30 막차 안전 탑승을 위한 **심야 줄서기 권장 시간대(23:50~00:10)** 안내

## 🛠 기술 스택 (Tech Stack)

* **Backend**: Python 3.10+, FastAPI (최신 lifespan 컨텍스트 매니저)
* **Frontend**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS, LocalStorage UUID
* **Data Source**: 
  * 공공데이터포털 (경기도 버스도착정보 API v2)
  * GBIS 경기도 버스정보시스템 (실시간 차량 위치 및 구간별 ptts 통과속도)
  * Open-Meteo (봉담/과천/사당 일대 실시간 기상 API)
* **Architecture**: 고속 인메모리 캐시(TTL 기반), 비동기 멀티스레드 I/O

## 💻 실행 방법 (Getting Started)

### 1. 환경 변수 설정
프로젝트 루트 경로에 `.env` 파일을 생성하고 공공데이터포털 인증키를 등록합니다.
```env
BUS_API_KEY=your_data_go_kr_service_key
```

### 2. 가상환경 구성 및 패키지 설치
```bash
# 가상환경 생성 및 활성화 (Windows PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1

# 필수 라이브러리 설치
pip install -r requirements.txt
```

### 3. 로컬 서버 실행
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
서버 실행 후 브라우저에서 `http://localhost:8000`으로 접속합니다.
