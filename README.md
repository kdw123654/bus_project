# 🚌 수원대 7790번 전세/일반 버스 판별기 (가칭: 7790 타요?)

> **"지금 오는 7790, 내가 탈 수 있는 버스일까?"**  
> 사당역에서 등교하는 수원대학교 학생들을 위해, 도착 예정인 7790번 버스가 **일반 광역버스(탑승 가능)**인지 **전세/예약버스(탑승 불가)**인지 실시간으로 판별해주는 모바일 웹 서비스입니다.

---

##  기획 배경 및 문제 정의
* **문제 상황**: 카카오맵, 네이버 지도 등 기존 지도 앱에서는 사당역으로 오는 7790번이 일반 버스인지 특정 통근/예약 전세버스인지 구별되지 않습니다.
* **불편 사항**: 
  - 탈 수 있는 버스인 줄 알고 기다렸다가 전세버스여서 수업에 지각하는 문제 발생
  - 반대로 탈 수 있는 버스를 전세버스인 줄 오해하고 비싼 택시를 타는 비용 낭비 발생
* **해결책**: 실시간 버스 공공데이터를 기반으로 차량 번호 및 노선 데이터를 분석하여, 학생들이 탑승 가능한 버스인지 직관적으로 알려줍니다.

---

##  주요 기능 (Features)
- ⏱ **실시간 도착 정보**: 사당역 기준 7790번 도착 예정 시간 및 잔여 좌석 확인
-  **스마트 탑승 판별**: 
  - 🟢 **일반 버스**: 탑승 가능 (안심하고 대기)
  - 🔴 **전세 버스**: 탑승 불가 / 예약 전용 (대체 교통수단 고려)
-  **모바일 최적화 UI**: 스마트폰 한 손 조작에 최적화된 모바일 웹 화면
- **원클릭 새로고침**: 초 단위로 바뀌는 도착 정보 즉시 갱신

---

##  기술 스택 (Tech Stack)
* **Backend**: Python, FastAPI
* **Frontend**: HTML5, Tailwind CSS, JavaScript
* **Data Source**: 공공데이터포털 (GBIS 경기도 버스정보시스템 / TAGO)
* **Version Control**: Git, GitHub
